## 실제 모델에서 막힌 위치

API 접속·인증·DB 읽기·모델 호출 자체는 성공했다. 초기 네 실행의 확인 질문은 PASS였지만 회사정보 요약은 PARTIAL이었다. 각각 불필요한 판정 설명, 수정 ID 불일치, 입력에서 한 근거 누락, 요청하지 않은 metadata/경력 연수까지 필수로 요구하는 coverage 판정이 관찰됐다. 중간 코드 변경과 실패 로그를 보존했다.

최종 `055755Z`에서는 첫 확인 질문에서 generate/validate/repair/revalidate 호출 모두 성공했으나 두 주장이 INSUFFICIENT로 처리됐다. 검증기는 질문 목록을 정리하는 요청에 회사 실적 증명서·등록 증빙까지 요구했고, 최종 결과는 원문 fallback/PARTIAL이었다. **최종 실행의 두 번째 질문은 첫 assertion 실패로 NOT_RUN**이다. 실패 문장 자체를 호출 trace에 보존하지 않았으므로 생성 문장의 과도한 단정과 검증기의 과업 오해의 기여도를 완전히 분리하지 못했다. 의미 검증을 통과하지 않은 문장을 그대로 게시하지는 않았다.

이번 실제 모델 실행 5회와 판별 대조군 비용의 usage 기반 보수 추정은 약 **$0.026633**이다. 과거 보고 $0.169586과 합쳐 약 **$0.196219**이며 실제 청구서 금액이 아니다. 회당 상한을 적용했고 승인된 $10보다 추가 예산이 필요한 상황은 아니다.
