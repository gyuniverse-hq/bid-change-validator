## 이번 핵심

1. 범용 기간 결과 0.0333 MONTH가 PERFORMANCE_AMOUNT로 들어가는 경로 차단. 최소 금액 하드코딩 없음.
2. 같은 값이라도 단위/필수 역할/기간/scope가 다르면 유지. 다른 OR 그룹의 동일 원자 연결도 유지.
3. 명확한 단일 업종 별칭만 정리. 같은 청크라고 별개 인증/허가를 제거하지 않음.
4. 나라장터 절차는 일반 인증 비교에서 분리하되 확인 의무를 없애지 않음. 미확인 경고와 근거 보존.
5. 실제 원문 구간 복원/타 조항 값 차단/숫자 부분 인용 차단/탈락 상세 진단 API 저장.
6. 신규 실행에 슬롯 파이프라인 버전 기록. 기존 저장 실행은 덮어쓰지 않음.
