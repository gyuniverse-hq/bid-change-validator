## 변경

- 평가 middleware에서 외부 처리·의미 처리 없는 기존 QUALIFICATION_SUMMARY/REQUIRED_CHECKS/ACTION_REQUEST 요청을 허용한다. 임의 구형 대화·원문 전송·의미 처리 요청은 계속 차단한다. 제품 controller와 API 계약은 바꾸지 않는다. 새 저장·모델 호출을 위한 우회가 아니다.
- 재검토 실패 시 loadCaseWorkspace로 현재 저장 기준을 다시 읽는다. 새 분석과 맞지 않는 옛 판정을 임의로 현재 판정으로 복원하지 않는다. 재조회도 실패하면 그 사실을 안내한다. 화면 이동 후 늦은 응답은 generation 검사로 무시한다.
- 제안의 현장 방문/운반 계약 JSON을 완전한 필드·boolean 형태일 때만 한국어로 표시한다. false를 정확히 ‘아니요’로 표시한다. 알 수 없는 구조는 추정하지 않는다.
- PARTIAL의 주 안내·완료 문구·상태 라벨을 ‘전체 조건 검토 미완료’로 정리한다. PARTIAL만으로 첨부 추출 실패를 단정하지 않으며 실제 진단과 원문 확인을 안내한다. Q-009는 미확정 그대로다.
