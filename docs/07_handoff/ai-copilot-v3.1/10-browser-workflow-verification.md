- `064352Z`: 실제 브라우저 화면에는 세 번째 답변이 도착했지만 비동기 응답 기록은 두 건인 순간 assertion이 실행돼 FAIL. 검사 도구가 응답 JSON 기록의 완료를 기다리도록 수정했다. `064521Z`와 최종 `065408Z`에서 통과했다.
