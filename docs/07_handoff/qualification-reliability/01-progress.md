## 현재까지 연결된 것

1. 원문 블록/차수/출처 기반 candidate ID와 처리 누락 검사.
2. 상위 조항·각주·참조 힌트, 요청 분할, 실제 요청 범위와 SHA-256.
3. 기존 structured extractor 호출 계약에 연결한 후보별 추출 실행.
4. 응답 형식/ID/인용을 검증하고 미응답 대상만 제한적으로 재요청.
5. 자기 조항 안의 값은 기존 normalization/canonical 경로로 전달.
6. 문맥 의존/복수 출처/별표 미해결은 억지로 합치지 않고 보류.
7. 새 경로의 호출·누락·미해결·참조 위치 기록을 REVIEW_EXECUTION_AUDIT에 보존.

## 검증 이력과 한계

2단계 당시: 기존 27개 + 신규 43개 = 70개 단위 테스트 통과.
3단계 이번: 신규 실행/변환 53개 + provider/분기 연결 12개 = 65개 테스트 통과.
이전 70개를 이번에 재실행한 것으로 합산하지 않는다.

새 모듈과 기존 provider는 실제 파일로 검증했다. 모델 I/O 및 orchestration 테스트의
기존 후단 의존성은 테스트 대역이다. 전체 API/실제 canonical·판정기 통합/DB/LLM/
브라우저/Copilot 검증은 미실행이다. 모든 후보 응답이 있다고 의미까지 옳다는 뜻이 아니다.
