# 사용자 평가 준비표 — 평가 진행 중

2026-09-15 갱신: 사용자가 U02 확인 질문에서 근거 혼합·불필요한 질문을 보고했다. **사용자 평가 실패 → 코드 보완 및 회귀검사 통과 → J13/J14 실모델 재검증 통과·사용자 재평가 대기**다. 상세 근거와 현재 순서는 [21번 보고서](21-user-evaluation-check-scope-fix.md)를 우선한다. 아래 초기 준비 시점의 NOT_RUN 및 개발 검증은 과거 기록이다.

현재는 **4의 Q-009 해석 확인을 기다리면서 5의 로컬 평가 환경 준비를 완료**한 상태다. 전체 순서는 1 감사 → 2 구현·연결 → 3 기본 검사 → 4 통합 검증 → **5 사용자 평가(다음)** → 6 최종 통합 판단이다. 접속·계정·실행 근거는 [20번 로컬 평가 안내](20-local-user-evaluation-ready.md)에 있다.

18번은 이전 보완 기록이며, 장문·해석 검수는 [19번 보고서](19-completion-scope-and-q009-review.md), 최신 환경 준비는 20번에 기록했다. Q-007 참가자격/작성·제출 두 장문 요청은 실모델 검사를 통과했다. Q-009는 공식 화면과 첨부 공고문 간 불일치가 확인되어 기관 해석 확인을 기다린다. 고정 평가 환경은 준비했고 업종군 관계와 합성 프로필 보충값 검수는 남아 있다. 자동 검사 통과를 사람의 이해도·자유 질문 성공으로 대신하지 않는다. 현재 사람 평가 결과는 모두 NOT_RUN이다.

## 평가 환경

- 후보 코드: `codex/ai-copilot-evaluation-ready`, 별도 worktree `.ci-results/evaluation-ready`.
- 공용 DB의 자료를 변경하는 평가를 하지 않는다. 전용 로컬 PostgreSQL에 출처가 고정된 자료와 검수한 합성 프로필을 적재한다.
- 자동 테스트 runner 계정과 별도로 전용 로컬 DB에 `eval-j13`~`eval-j16` 고정 USER 계정을 준비했다. 비밀번호는 로컬 전용 시작 안내에 있고 GitHub에는 올리지 않는다. 실제 로그인·회사 경계·Chrome 실모델 요약을 확인했다.
- 일반 개발 경로는 의미 처리 OFF 기본값을 확인하고, 실모델 평가를 할 때 사용자가 의미 처리와 공고문 처리 동의를 각각 켠다.
- 남원 자료는 저장 DB snapshot의 별도 재추출본이다. v1/v2 HWP·PDF 원본 byte hash와 PDF 참가자격 페이지의 시각 대조를 확인했다. 이는 전체 문서의 독립 사람 검수나 발주기관의 법적 해석 확정이 아니다. 이 자료는 000→001 과거 변경 사례이며 최종 공고가 아니다.
- 세션마다 코드 commit, snapshot/fixture hash, 회사 프로필, 기준·현재 분석/판정 ID, 규칙 버전, 모델, 동의 상태를 기록한다.

정답표와 개발용 질문을 미리 본 사람이 독립 평가자라고 주장하지 않는다. 평가자는 답변의 어색함뿐 아니라 목적 달성, 조건/예외 누락, 잘못된 확정, 근거 접근, 추가 질문 횟수를 기록한다.
